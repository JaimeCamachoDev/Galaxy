# **Galaxy**

_**Galaxia con VFX Graph en Unity 6 URP**_

</header>

## Requisitos

* Unity **6000.0.58f2**
* Render Pipeline: Universal Render Pipeline (URP)
* Paquetes: Visual Effect Graph

## Contenido

* **VFX Graph:** `Galaxy`, `Galaxy_SubFX`
* **Shader Graph:** `AntiAliasedQuadStrip`, `Clouds`, `FlipbookBlendGalaxy`, `VFX-Dot-HardStep`
* **Prefabs:** `VFX_Galaxy`
* **Escenas:** `Assets/3-Scenes/Galaxy.unity`, `Assets/3-Scenes/Main.unity`

## Uso

1. Clona el repositorio y añádelo en Unity Hub (*Add project from disk*).
2. Ábrelo con Unity **6000.0.58f2**.
3. Abre la escena `Assets/3-Scenes/Galaxy.unity` y pulsa **Play**.
